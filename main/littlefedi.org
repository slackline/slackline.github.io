#+TITLE: LittleFedi
#+DATE: [2026-10-01 Thu]
#+FILETAGS: :fediverse:mastodon:blog:

[[https://littlefedi.org/][littleFedi]] is "/a small AcitivtyPub Server written in Go/" for connecting to the [[id:8178219c-ef79-4b59-ad51-e4204a8f369c][Fediverse]] and in particular
[[id:0a7fbe90-1f6e-4a38-a0c8-b378b1893f33][Mastodon]]. It also includes the ability to blog.

* Initial Test

Downloading a binary and placing it on my [[id:e1dcf5fc-2125-455d-b800-d3f1b318c8c9][OVH]] VPS I made it executable and ran ~littlefedi init~ setting it up as an
instance with a sub-domain on my server. I could then connect to it locally, good start.

Setting up a ~CNAME~ entry for the public domain was straight forward (I also use OVH for this).

I needed to setup a proxy in [[id:3774439d-af75-453e-b3e9-9d578b6bec46][Nginx]] in order to be able to connect to it remotely. Fortunately I already use one for
[[id:d9c960c2-71b6-45e6-b388-dcd07b9da3e1][FitTrackee]] so had a starting point but the authors also provide one in the [[https://littlefedi.org/downloads/binaries/packaging/][~packaging/nginx-littlefedi.conf~]].

** Build from source

First check that I can build from source.

#+begin_example shell
wget https://littlefedi.org/downloads/littlefedi-26.10.01-source.tar.gz
tar xzvf littlefedi-26.10.01-source.tar.gz
cd littlefedi-26.10.01
#+end_example

There are multiple options available depending on the features to enable, I decided to try including the ~blog~ feature,
(according to the ~README.md~ inclusion of [[id:749d5f0f-09bd-47a8-a351-2432f38ff3d9][SQLite3]] happens with all targets, it's not clear why there is a "~make
build-sqlite~ option in the ~Makefile~.

#+begin_example
make build-blog
#+end_example

This froze (or dramatically slowed down) my VPS which only has 2GB RAM and I expect this was exceeded so it switched to
caching (I saw a [[https://0xde501a7a.net/@rqm/01a105d4-b580-7ed6-a06e-680aeb2852ce][toot]] suggesting it could use up to
19.7GB albeit with ~allreleases~ so perhaps that is for all architectures that are available).

I therefore switched to using my [[id:84523969-a4c2-4349-ac23-09894939ed54][T490]] which also runs [[id:a53fa3c5-f091-4715-a1a4-a94071407abf][Arch Linux]] where it completed fine.

** Setup a clean ~chroot~

That worked, next is checking the package builds in a [[https://wiki.archlinux.org/title/DeveloperWiki:Building_in_a_clean_chroot][clean ~chroot~ environment]]. I opted for the "Classic way"

#+begin_example
sudo pacman -Sy devtools
mkdir ~/chroot
CHROOT=$HOME/chroot
mkarchroot $CHROOT/root base-devel

#+end_example

We return to this later, first we need to write our ~PKGBUILD~

** ~PKGBUILD~

[[https://wiki.archlinux.org/title/PKGBUILD][~PKGBUILD~]] is the file that says how packages should be built and includes additional files for installation such as
configuration and [[id:9bc6a091-ed02-4423-b14a-d56f677c5cd0][Systemd]] unit files and so forth.

#+begin_example
# Maintainer: Neil <nshephard at protonmail dot com>
pkgname=littlefedi
pkgrel=1
pkgdesc="A small ActivityPub server written in Go with SQLite, local media storage and a web interface that
works without JavaScript."
url="https://littlefedi.org/"
license=('MIT')
makedepends=('go')
install=
changelog=
source=("${url}/downloads/${pkgname}-${pkgver}-source.tar.gz")
noextract=()
sha256sums=('55a8e305893dc7f72f2062406a941b9efb397c6548d909213a621fabb9d17f44')
validpgpkeys=()



build() {
    cd "${pkgname}-${pkgver}"
    make build-blog
}

prepare() {
        cd "${srcdir}/${pkgname}-${pkgver}/packaging/linux"
        # .service files look for binaries in /usr/local/bin/ switch to /usr/bin/
        sed -i "s/local\///" *.service
        # Switch user to root in service file (unclear how to create user/groups post_install() doesn't appear to run)
        sed -i "s/=littlefedi/=root/" littlefedi.service
}

package() {
        install -Dm 755 "${pkgname}-${pkgver}/littlefedi-blog" "${pkgdir}/usr/bin/littlefedi"
        install -Dm 644 "${pkgname}-${pkgver}/config/littlefedi.toml.example"
"${pkgdir}/etc/littlefedi/littlefedi.toml.example"
        install -Dm 644 "${pkgname}-${pkgver}/config/config.go" "${pkgdir}/etc/littlefedi/config.go"
        install -Dm 644 "${pkgname}-${pkgver}/config/littlemesh-directory.toml.example"
"${pkgdir}/etc/littlefedi/littlemesh-directory.toml.example"
        install -Dm 644 "${pkgname}-${pkgver}/packaging/linux/littlefedi.service"
"${pkgdir}/usr/lib/systemd/system/littlefedi.service"
        install -Dm 644 "${pkgname}-${pkgver}/packaging/linux/littlefedi-directory.service"
"${pkgdir}/usr/lib/systemd/system/littlefedi-directory.service"
        install -Dm 644 "${pkgname}-${pkgver}/packaging/linux/littlefedi-lighthouse.service"
"${pkgdir}/usr/lib/systemd/system/littlefedi-lighthouse.service"
        touch "${pkgdir}/etc/littlefedi/littlefedi.env"
        install -Dm 644 "${pkgname}-${pkgver}/LICENSE" "${pkgdir}/usr/share/licenses/littlefedi/LICENSE"
        mkdir -p "${pkgdir}/var/lib/littlefedi"
}

post_install() {
        useradd --no-create-home --user-group littlefedi
        chown -R littleffedi:littlefedi /var/lib/littlefedi

        echo ""
        echo "LittleFedi"
        echo "=========="
        echo ""
        echo "To get started with LittleFedi answer the prompts to..."
        echo ""
        echo "  littlefedi init [--config /etc/littlefedi/littlefedi.toml]"
        echo ""
        echo "The resulting configuration file can be edited and you should"
        echo "consult the '/etc/littlefedi/littlefedi.toml.example for more"
        echo "options."
        echo ""
        echo "See also the official documentation for mor information : "
        echo ""
        echo "https://littlefedi.org/docs.html"
}

#+end_example

This builds and installs the package as well as installing the ~LICENSE~ and ~*.service~ files. In order to start the
service we need to [[https://soc.0x47.org/@rooty/01a16dbc-c8fd-7248-9ea7-5eb321b1a1cf][add an empty littlefedi.env]] file.

Test whether the package builds using...

#+end_example

Next try installing the package locally with ~makepkg -sri~ and running the programme. If it has a [[id:9bc6a091-ed02-4423-b14a-d56f677c5cd0][Systemd]] unit file

*** ~.SRCINFO~

Once happy generate a [[https://wiki.archlinux.org/title/.SRCINFO][~.SRCINFO~]] file.

#+begin_example
makepkg --printsrcinfo > .SRCINFO
#+end_example

This is required as part of the submission to AUR.

*** Checking Package

There are still a few checks to make to ensure the package builds. Requires a few tools to be installed

#+begin_example
pacman -Syu devtools namcap
#+end_example

**** Clean chroot environment

Test building in a clean ~chroot~ environment with ~pkgctl~ (part of ~devtools~).

#+begin_example
pkgctl build
#+end_example

**** Package Sanity

This step is automatically run as part of ~pkgctl build~ and leaves log-files in the working directory.
#+begin_example
namcap PKGBUILD
namcap littlefedi-23.10.13-1-any.pkg.tar.zst
#+end_example
