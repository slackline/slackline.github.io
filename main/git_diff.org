* Alternatives

** [[https://difftastic.wilfred.me.uk/][Difftastic]]

Is an excellent, code aware, diffing tool that shows differences side by side and is easy to drop in as a default
replacement to the standard ~git diff~

* Patterns

You can subset diffs in many different ways.

** Excluding Directories

Via a [[https://mas.to/@DHowett/117524913168134064][post on Mastodon]]

#+begin_example
git diff ":(exclude)subdir"
#+end_example
