** Adblocking

Traditionally I've used plain ~adblock~ but after reading [[https://forum.openwrt.org/t/the-best-package-to-encrypt-your-dns-traffic/92363/3][this]] thread decided to give [[https://docs.mossdef.org/adblock-fast/][~adblock-fast~]] and [[https://nlnetlabs.nl/projects/unbound/about/][unbound]] a
whirl. The [[https://github.com/openwrt/packages/blob/master/net/unbound/files/README.md][unbound README.md]] is worth reading.


#+begin_example
apk add luci-app-adblock-fast luci-app-unbound unbound-host unbound-daemon unbound-control \
  unbound-control-setup unbound-checkconf
#+end_example

As advised enable ~adblock-fast~

#+begin_example
uci set adblock-fast.config.enabled='1'
uci commit adblock-fast
#+end_example

I found it failed to start and had to manually install...

#+begin_example
apk add gawk grep sed coreutils-sort
#+end_example

Even then it failed to start but that was because I needed to select some blocklists to include!

I enabled Unbound and also enabled the DNSSEC option from the /Unbound > Recursive DNS > Basic/ configuration tab.
* Upgrading

Strategy

1. Setup [[id:d34e7955-6aa1-4069-bfb0-b54bc067c749][OpenWRT : GL.iNet GL-AX1800 (Flint)]] and mirror services (see below).
2. Connect router to laptop and upgrade
3. Setup/mirror services
4. Switch out GL-AX1800 and put shiny new WRT1900ACS back in place.

** Configuration and Services

+ Ad-block is required
+ Port forwarding (see [[file:openwrt_secrets.org.gpg][table]])
+ Static IP Address for ~kimura~ (~192.168.1.45~) and ~alarmpi-4b~ (~192.168.1.28~) and ~crow~ (~192.168.1.46~) (see
  [[file:openwrt_secrets.org.gpg][table]])
+ Add SSH public key and set SSH port to 418, allow ~root~ SSH temporarily but once upgraded add a user and their key
  and disable ~root~ login.



* Extensions

the LuCI WebUI.
