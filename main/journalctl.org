#+TITLE: Journalctl
#+FILETAGS: :linux:systemd:logging:

* Configuration

** Limit log file size

~/etc/systemd/journald.conf~

#+begin_example
[Journal]
SystemMaxUse=512M     # Total journal size
RuntimeMaxUse=128M    # Journal size in temp storage
MaxFileSec=1month     # Log retention time
#+end_example


* Options

** Check journal disk usage

#+begin_example
journalctl --disk-usage
#+end_example

** Current boot

#+begin_example
journalctl -b -0
#+end_example

** Last boot

#+begin_example
journalctl -b -1
#+end_example

** Time Window

#+begin_example
journactl --since="YYYY-MM-DD [hh:mm:ss]" --until="YYYY-MM-DD [hh:mm:ss]"
#+end_example

** Last ~n~ lines

#+begin_example
journalctl -n 100
#+end_example

** Monitor live errors

#+begin_example
journalctl -f -p err
#+end_example

** Specific service

#+begin_example
journalctl -u nginx.service
#+end_example
