* Tips and Tricks

** Edit files in place

Using the ~-i~ flag will edit a file in place. But if you use ~-i.bak~ then you also get a backup of the original file
which carries the extension ~.bak~.

#+begin_example
sed -i.bak 's/this/that/g' input.file
#+end_example
