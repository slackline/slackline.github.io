[[id:754f25a5-3429-4504-8a17-4efea1568eba][Emacs]] users live and die by their [[id:6bb6b516-a3df-452a-adb3-f5aa8a32857c][Key Bindings]] (or "chords"). The following are specific to navigation.

| Key Sequence | Action                                               |
|--------------+------------------------------------------------------|
| ~C-f~        | Forward one character                                |
| ~C-b~        | Back one character                                   |
| ~C-n~        | Next line                                            |
| ~C-p~        | Previous line                                        |
| ~C-M-n~      | Forward a parenthetical group ( ~()~ / ~[]~ / ~{}~)  |
| ~C-M-p~      | Backward a parenthetical group ( ~()~ / ~[]~ / ~{}~) |
| ~M-f~        | Forward one word boundary                            |
| ~M-b~        | Back one word boundary                               |
| ~M-S-Up~     | Move line up                                         |
| ~M-S-Down~   | Move line down                                       |
| ~C-d~        | Delete next character                                |
|              |                                                      |


I'm working on switching to these but have a bad habit of having used [[id:0b7373ce-724c-40f0-8432-f8dbbbad95fc][Ergonomic Keyboard]] with directional arrows and
additional keys for many years and my right hand regularly drifts to these thanks to ingrained muscle memory.

* Cool Navigation Tricks

** ~occur~

You can use ~occur~ (bound to ~M-s o~) to search for the occurrence of a string (or regex?) which will open a buffer
with lines that match. You can switch to this and use it to jump to the occurence in the buffer you are working
with. Better still you can press ~e~ within this buffer to edit all occurrences. In essence a fancy find and replace but
handy for navigating and getting context.
